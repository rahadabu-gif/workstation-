1. Download Standalone App File (.html)

এক ক্লিকে সম্পূর্ণ অ্যাপটি আপনার ফোন বা কম্পিউটারে ডাউনলোড করুন। এটি ইন্টারনেট ছাড়াই চলবে এবং বন্ধুদের শেয়ার করতে পারবেন।

2. Install as Phone App Icon

আপনার ফোনের ব্রাউজারের মেনু (⋮) থেকে "Add to Home screen" চাপলে এটি আসল অ্যাপের মতো হোম স্ক্রিনে বসে যাবে।

3. Save or Restore Your Personal Data (.json)

আপনার সব কাজ অটোমেটিক সেভ হচ্ছে। এছাড়াও নিচের বাটনে ক্লিক করে আপনার ডাটা ফাইল ডাউনলোড বা রিস্টোর করতে পারবেন।

4. Physically Block Facebook (Android App Pinning)

  1. Open phone Settings → Security → App Pinning and turn it ON.
  2. Open Workstation OS, swipe up to Recent Apps, tap the top icon and select Pin.
  3. Your phone is now physically locked inside Workstation OS until you enter your lock-screen PIN.
